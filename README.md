# 🚂 HARDCORE TRAINS

check the game: https://vistemur.github.io/hardcoreTrains

web game made with `javascript` and [p5js](https://p5js.org/) library

you play as a train and create a bullet hell (super hardcore)

## 🎮 Controls

use arrow keys to move up and down

w and s for second player in pvp mode

## ✨ Features

* 3 gamemodes
* multiple maps
* upgrade system

## 🎯 Gamemodes

### 🛤️ PVP

play with friend on the same keyboard and spam each other with constant stream of bullets

gain 3 wins to become the most hardcore train

![Screenshot 2026-01-01 at 13 32 23](https://github.com/user-attachments/assets/5e150968-1024-4488-8431-67472e4a00bd)

### 🤖 PVE

if all of your friends are not hadcore enought, the blazing fast hardcorest AI will become your rival

### 🧟 Survival

wawes of enemies approach, you should stop them all!

kill enemies to upgrade your train by adding additional sections and improving them
